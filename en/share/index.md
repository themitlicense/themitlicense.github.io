The strongest way to spread this manifesto is to use it where it helps someone. A README badge gives visitors a path from a real project to the reasoning behind it. A thoughtful conversation can do the same.

## Three lines you can share

> The MIT License gives you the code. Not the developer.

> Your issue is a request, not a support contract.

> MIT lets you build a business. It doesn't turn a volunteer into your employee.

Each line is a starting point, not the whole argument. Link to the [manifesto](/en/manifesto/) so people can see the distinction between the license and the voluntary principle.

## Start a useful conversation

Ask maintainers what support expectations they struggle to explain. Ask users what information would help them file better issues. Invite disagreement about the wording. Do not assume that an MIT repository endorses this manifesto unless its maintainers say so.

## A shareable description

> Free Code. Not Free Labor. is an independent manifesto for respecting open-source maintainers. It supports the freedom of the MIT License while making clear that permission to use software does not create a claim on the author's time.

No automated issue campaigns or unsolicited badge pull requests. People should adopt this because it helps them, not because someone tried to make their repository a billboard.
