**Mantieni la licenza. Chiarisci le aspettative.** Scegli la forma adatta al progetto. Non servono iscrizione, permesso, pagamento o certificazione.

## 1. Scegli il segnale

Per repository MIT, inserisci il badge nel README insieme alle altre informazioni di progetto. Porta al manifesto e non sostituisce il normale badge `License: MIT`.

## 2. Oppure usa le parole

Una breve dichiarazione spiega il confine anche a chi non apre il link del badge.

Il software è disponibile secondo la licenza indicata in questo repository.

La versione neutra lascia spazio a eventuali impegni di assistenza assunti separatamente.

## 3. Inseriscilo nel posto giusto

Metti il testo nel README vicino alle sezioni su supporto o contributi. Conserva il file `LICENSE` e gli avvisi di copyright. Se offri assistenza a pagamento o hai un contratto, descrivilo a parte.

**Aderire significa sostenere un’idea.** Puoi rimuovere il link quando vuoi. Il badge non certifica il progetto, non cambia i diritti MIT degli utenti e non obbliga nessuno a contribuire.

<div class="note">Il badge MIT è per repository con licenza MIT. Per gli altri scegli quello generale o una dichiarazione testuale.</div>
